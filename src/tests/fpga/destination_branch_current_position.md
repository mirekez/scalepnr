# destination_branch_current_position

Reuse an opened branch at the original sink.

- Install a completed sibling and an unfinished branch of the same source.
- Retain the requested input beyond an explicit GAP.
- A real foreign transit blocks the required branch exit.
- An independent input at the original sink is already routed.
- The free current-position attempt must fail before the transit cut.
- Destination Moving may then open the permitted branch.
- The opened branch leads back to the original mapped input.
- The placement-only trace excludes that original position.
- It must not mark an incoming SRC dead when skipping its terminal LOCAL.
- That skipped terminal is a policy restriction, not exhausted connectivity.
- The following current-position attempt must use the opened route.
- Require completion without moving the sink or its driver.
- Keep the completed sibling and independent input intact.
- Retain and schedule the displaced transit victim.
- The disconnected companion control must not claim completion.
- Audit every remaining resource against its registered owner.

- Updated the existing case for recursive tracing and persistent deadends.

Coverage:

- Preserves positive completion, negative controls, and ownership assertions.

Fixture connectivity and node names are vendor-agnostic.
