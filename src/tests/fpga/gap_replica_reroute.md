# gap_replica_reroute

Shared retained island replacement.

- Install related bindings with a retained common routing island.
- Use genuine physical fragments and registered owners.
- Cover either ordinary or aliased net identity as named by the case.
- Cover an independent branch or a shared replica as named by the case.
- Repair the requesting GAP through the retained island.
- Check ownership of every reused SRC, DST, and local connector.
- An unrelated route must never acquire the shared resources.
- Keep the donor route available while the requester completes.
- Reroute the donor through its independent one-hop alternative.
- Pass the one-hop limit that defines this independent-route control.
- Do not require an arbitrary longer alternative to have the same shape.
- The requester must retain resources still needed after donor replacement.
- Check continuity and endpoint identity of both resulting paths.
- Unrouting either binding must preserve surviving shared leases.
- Final teardown must release all private resources.
- Audit masks and registrations against the live owner set.

- Revised the existing regression for recursive routing and immediate deadends.

Coverage:

- Uses production entry points and explicit ownership assertions.

Fixture connectivity and node names are vendor-agnostic.
